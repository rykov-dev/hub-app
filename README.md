# Deity

Продакшен-версия (ветка `main`): Inbox для мыслей и ежедневные серии. Хаб с чатом, игрой
и связями развивается в `dev`.
[Суть приложения и связь с hub](VISION.md).

- **Сегодня** — квесты на день и мягкая подсказка «1–3 посильных дела»; начало дня отмечается
  по первому входу.
- **Inbox** — быстрые записи с необязательным типом (заметка, событие, ссылка, расход, питание),
  изображением, тегами и комментариями; текст и дату можно править, тип — нет. Приём ссылок
  и изображений через «Поделиться» на Android (установленное PWA).
- **Квесты** — поддержание, развитие, исследование, эксперимент; дата, время или весь день,
  повтор. Статусы на день: выполнен, отложен, отклонён — без штрафов.
- **История** — записи, статусы квестов и начала дней по датам; экспорт в Markdown и JSON.
- **Серия** — заходи каждый день: монетки за визит и бонус за дни подряд.
- **Офлайн** — всё, кроме получения наград, работает без сети и синхронизируется потом.

React + Rsbuild фронтенд, Supabase (Postgres, Auth, Edge Functions) вместо бэкенда.
Вход через Google, GitHub или по email и паролю (Supabase Auth), без подтверждения почты
и без отправки писем.

## Хранение данных

Записи (`inbox_notes`), комментарии (`inbox_note_comments`), квесты (`quests`, `quest_logs`)
и начала дней (`day_starts`) хранятся в Supabase Postgres открытым текстом, изображения — в приватном
bucket `attachments` Supabase Storage (папка пользователя, до 5 МБ; на устройстве уменьшаются
до 1600 px). Доступ ограничен Supabase Auth и RLS, транспорт — HTTPS. Клиентского шифрования нет:
Deity Vault из v1.0.0 убран в v1.0.1, данные при переходе стёрты. Подробнее и о возможном возврате
шифрования — [docs/encryption.md](docs/encryption.md) и [docs/vault-migration.md](docs/vault-migration.md).

## Награды

| Награда | Сколько | Когда |
|---|---|---|
| Ежедневный визит | 10 | первый заход за сутки (UTC) |
| Бонус за серию | +5 за каждый день подряд, максимум +30 с 7-го дня | вместе с ежедневной наградой |

Монеты начисляются только на сервере: edge function `claim-daily` вызывает `claim_daily_reward`
в Postgres, доступную только `service_role`. Каждая награда записывается в `coin_transactions`
с уникальным ключом на `(user_id, reason, day)`, поэтому повторно её не получить. Константы —
в `supabase/migrations/*_coins.sql` (`streak_bonus`, `v_daily_reward`). За заметки монеты
не начисляются (с v1.0.2).

## Офлайн

- Service worker кэширует оболочку приложения: после первого визита оно открывается без сети.
- Профиль, монеты, история, заметки и комментарии хранятся в IndexedDB (`src/lib/offline/`):
  экран сразу показывает сохранённое и обновляет его с сервера.
- Записи, их правки, теги, комментарии, квесты и их статусы, начало дня и удаление всегда проходят
  через очередь (`outbox.ts`): видны сразу, а на сервер уходят, когда есть сеть. Id генерирует
  клиент, поэтому повторная отправка не создаёт дубликатов.
- Изображение до отправки хранится в IndexedDB и загружается перед записью; просмотренные
  изображения кэшируются и открываются без сети.
- «Поделиться» (`share_target` в манифесте): service worker сохраняет присланное в Cache Storage
  и открывает приложение, которое подставляет его в форму записи (и после входа в аккаунт).
- Награды требуют сервера: ежедневная награда начисляется при появлении сети.
- При выходе офлайн-данные удаляются с устройства, кроме несинхронизированных изменений.
- Версия офлайн-данных — `LOCAL_DATA_VERSION` в `src/lib/offline/storage.ts`. Если на устройстве
  данные старой версии, при запуске они стираются целиком (так убраны ключ и кэш Vault из v1.0.0).
