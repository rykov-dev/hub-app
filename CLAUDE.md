# Правила проекта

## Ветки

- Все правки и изменения делаются только в `main`.
- `release` содержит только выпущенную версию: в неё попадают лишь cherry-pick нужных коммитов
  из `main` (`git cherry-pick -x`). Своих коммитов и merge в `release` не делаем; если для релиза
  что-то нужно поправить — сначала коммит в `main`, потом cherry-pick. Версия — тег `vX.Y.Z` на `release`.
  Push в `release` деплоит сайт.
- Порядок выпуска — раздел «Ветки и релизы» в README.md.

## Данные

- Данные хранятся без клиентского шифрования (Postgres + RLS), см. docs/encryption.md.
- `scripts/reset-user-data.sql` — только ручной запуск, не класть в `supabase/migrations`.
